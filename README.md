# nexus-mcp (archived)

This project was absorbed into [cursor-bridge](https://github.com/KloutDevs/cursor-bridge) on
2026-09-06. Its multi-window/multi-tab Cursor control tools now live in
`cursor-bridge/src/index.ts`, alongside filesystem tools and the `cursor-mcp-bridge` extension.

Do not install this MCP going forward — use `cursor-bridge` instead.
